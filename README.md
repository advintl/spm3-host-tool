# SPM-3 電錶通訊測試工具

Windows 單一執行檔(免安裝)。接上 USB 轉 RS485 後,自動找出士林電機 SPM-3 多功能電錶的通訊參數(Baud / 站號),讀取並顯示即時量測數值,供現場與電錶 LCD 顯示值比對確認。

**目前版本:v0.1.0(預覽版)** — 本 repo 只提供可執行檔下載,不含原始碼。

## 下載

到 [Releases](../../releases/latest) 下載 `SPM3HostTool.exe`(約 72 MB,不需要登入)。

系統需求:Windows 10 1809 或更新版本、64 位元。不需要另外安裝 .NET 或任何執行環境。

## 用法

1. 把 USB 轉 RS485 轉換器接到 SPM-3 的 RS485 端子(D+ / D- / COM),再插上電腦。SPM-3 出廠通訊參數為 19200 bps、8N1、站號 15。
2. 直接執行 `SPM3HostTool.exe`(免安裝)。
3. 若使用 **FTDI** 的轉換器且電腦尚未安裝驅動,程式會詢問是否安裝內嵌的驅動(需要系統管理員權限,UAC 按「是」,只需一次)。
4. 驅動就緒後會自動開始掃描;若使用其他廠牌的轉換器(例如 CH340),請在左上角 **COM Port** 下拉選單選擇埠,再按「開始掃描」。
5. 找到電表後,畫面每秒更新一次(頁尾可改為 0.5 / 1 / 2 / 5 秒),顯示電壓、電流、頻率、功率、功率因數、電度與需量,請與電錶 LCD 顯示值逐項比對。

畫面按鈕:

| 按鈕 | 說明 |
|---|---|
| 更新 | 重新整理 COM Port 清單(插拔 USB 也會自動更新) |
| 開始掃描 / 重新掃描 | 自動尋找電表的通訊參數 |
| 取消掃描 | 中止掃描 |

### 掃描說明

- 先嘗試手冊預設值(19200 bps、8N1、站號 15),命中時不到 1 秒。
- 找不到才依序嘗試 Baud 19200 / 9600 / 4800 / 38400 / 57600 × 站號 1–255,約 155 秒可掃完一輪;仍找不到才改用 Stop Bit 2 再掃一輪。整個組合空間都沒有回應時,最長約 5 分鐘。

## 顯示的資料

一次 Modbus RTU 讀取(Function Code 04,起始位址 0x1000,63 個暫存器)取得全部數值:

- 電壓:相電壓 Van / Vbn / Vcn / 平均,線電壓 Vab / Vbc / Vca / 平均
- 電流:Ia / Ib / Ic / 平均,頻率
- 功率:kW、kvar、kVA(各相與總和)、功率因數 PF
- 電度:kWh、kvarh、kVAh
- 需量:前一週期與目前 kW 需量、剩餘時間

## 已知限制

- **尚未以實體 SPM-3 驗證**:開發與測試使用 Modbus RTU 從站模擬程式。顯示數值尚未與實體電錶 LCD 逐項比對。
- **逾時餘裕以模擬器校準**:掃描等待回應的時間為「傳輸時間 + 100 ms」,約可涵蓋回應延遲 60 ms 以內的電表;若實體電表回應更慢,自動掃描可能找不到,請到本 repo 的 Issues 回報。
- **驅動自動安裝僅涵蓋 FTDI**:內嵌驅動只支援 FTDI(VID_0403 / PID_6001)轉換器、僅 64 位元;驅動偵測與安裝流程已在一台乾淨電腦上驗證正常(驗證的機器數有限)。其他廠牌轉換器須自行安裝驅動,再手動選擇 COM Port。
- **未經數位簽章**:第一次開啟時 Windows SmartScreen 可能顯示「Windows 已保護您的電腦」,請按「其他資訊」→「仍要執行」;部分防毒軟體也可能誤報。Release 說明附有 SHA256,可用來核對檔案完整性。
- **唯讀**:只讀取即時資料,不支援讀寫電表設定,也不提供諧波、最大最小值、事件紀錄等其他暫存器。
- **假設 RS485 匯流排上只有一台 SPM-3**:掃描以第一個有效回應為準,不區分匯流排上的其他 Modbus 裝置。
- 掃描參數範圍:Baud 4800–57600、站號 1–255、無同位;不支援其他 Baud 或同位設定。
- 高 DPI(125% 以上)螢幕縮放僅做過模擬驗證。
- 僅支援 Windows,不提供其他作業系統版本。
